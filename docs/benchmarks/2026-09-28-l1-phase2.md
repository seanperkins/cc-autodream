- Agreement is measured against the frozen reference (majority of the reference models, adjudicated by you). Findings: recall is the share of the reference's confirmed findings the candidate reported; precision (strict) counts a candidate finding only if it matches a confirmed one, precision (lenient) also accepts findings only one reference model reported.
- Goal and finding matches are judged by a model that is never the candidate. `unjudged` counts comparisons whose judge call failed; they are excluded, never guessed.

## Notes

- `abstain_excess` is measured against the frozen reference outcome for the same session (cases the reference left undecided or excluded are not counted).
- Rates show a 95% Wilson interval and the denominator. Differences smaller than the interval are within noise.
- Evidence is graded in tiers: verbatim quote, else anchored (its quoted commands and identifiers appear in the transcript), else unverifiable (nothing checkable) or ungrounded. Only ungrounded counts as hallucinated. Production L1 mostly paraphrases, so verbatim is informational.
- Cost is the CLI's API-equivalent list cost, shown for information: runs use the subscription.

## Acceptance (2026-09-29)

**Reference.** Built from Opus 5.5 and Fable 5.1 (through `claude`) and GPT-6 Astra (through `codex`), each at high effort on the 60 frozen sessions: 60 of 60 valid outputs from every model, 0 errors. Outcomes: 40 unanimous, 20 majority, 0 three-way splits, 0 excluded. Findings: 34 confirmed (two or more models) and 37 unconfirmed. The judge (Fable 5.1, Opus 5.5 for the Fable run) made 538 cached comparisons with 0 failures. The reference was spot-checked by the user: 11 of 11 ruled cases OK, 4 of 15 left unruled (kept in the reference).

**Against the reference (outcome exact match, 60 cases).**

| run | outcome match | finding recall (34 confirmed) | strict precision |
|---|---|---|---|
| Opus 5.5 (reference seat) | 54/60 | 28/34 | 28/36 |
| Fable 5.1 (reference seat) | 55/60 | 34/34 | 34/62 |
| GPT-6 Astra (reference seat) | 51/60 | 26/34 | 26/31 |
| **Haiku 4.5, fresh run** | **35/60** | **8/34** | **8/15** |
| Haiku 4.5, historical output | 36/60 | 9/34 | 9/20 |
| **Sonnet 5.5, `low`** | **2/60** | **0/34** | no findings |

Sonnet 5.5 at `low` and `medium` score far below Haiku on outcome match and finding recall, and the reference models score far above both, which meets the acceptance criteria.

**Depth gate against the reference.** `abstain_excess` (says `unclear_from_transcript` where the reference decided) is 58/58 for Sonnet `low`, 47/58 for `medium`, and 0/58, 2/58 and 4/58 for the Fable, Opus and Astra reference seats. **Haiku is 7/58 (12%) on the fresh run and identically 7/58 on the historical run, which is above the 10% ceiling in `config.json`.** That ceiling was set when Haiku was its own stand-in reference, so it fails the incumbent; whether to raise it is a decision for the maintainer, not made here.

**Caveats.**

- The reference seats score against a reference they helped build, so their rows are optimistic (Fable's recall of 34/34 is close to by construction). Compare candidates with each other, not with the seats.
- GPT-6 Astra returned the L1 prompt's error object on 6 of 6 real cases with the unmodified prompt, because it parses the slimmed transcript as strict JSON. The codex harness adds the production worker instructions and one sentence saying truncated lines are plain text (4 of 4 valid with it). Astra as a plain candidate does not meet the unmodified L1 contract.
- A null `underlying_goal` is scored by the candidate's top initiative (the L1 prompt defines null as "duplicates the initiative"). Before that fix Astra scored 2/24 on goals; after, 14/24 same and 24/24 same-or-partial.
- Only 34 confirmed findings exist, so recall and precision intervals are wide.
- The same Fable judge clusters the reference outputs including Fable's own, and 4 spot checks are unruled.

**Update (2026-09-29):** `abstain_excess_max` was raised from 10% to 15% in `bench/config.json`, so Haiku 4.5 (12%) passes the depth gate against the reference while Sonnet 5.5 at `low` and `medium` (100% and 81%) still fail it.
